# Як встановити «Міста» · How to install Cities

[Українська](#українська) · [English](#english)

The files are on the [Releases page](https://github.com/dariakyselytsia/cities/releases):
`…-android.apk` for Android, `…-ios.ipa` for iPhone.

---

## Українська

Це тестова версія для друзів, поки гри немає в Google Play та App Store.
Гра працює повністю офлайн і не збирає жодних даних
([політика конфіденційності](https://dariakyselytsia.github.io/cities/privacy/)).

### Android

1. На телефоні відкрийте [сторінку релізів](https://github.com/dariakyselytsia/cities/releases)
   і завантажте файл `…-android.apk` з найновішого релізу.
2. Відкрийте завантажений файл. Телефон попросить дозволити встановлення
   з цього джерела («Встановлення невідомих застосунків»): дозвольте один
   раз для браузера або «Файлів».
3. Натисніть **Встановити**. Якщо Google Play Protect попередить про
   невідомого розробника, натисніть **Докладніше → Усе одно встановити**.

**Оновлення:** просто встановіть новіший `.apk` поверх старого. Ваш прогрес
збережеться.

### iPhone

Apple не дозволяє встановлювати застосунки поза App Store без платного
акаунта розробника. Безкоштовний спосіб: підписати гру **своїм Apple ID**
за допомогою програми **Sideloadly** на комп'ютері з Windows або Mac.
Потрібні кабель USB і приблизно 20 хвилин першого разу.

**Один раз на комп'ютері:**
1. На Windows встановіть **iTunes** та **iCloud** із сайту Apple (не з
   Microsoft Store): Sideloadly без них не бачить iPhone.
2. Встановіть [Sideloadly](https://sideloadly.io/).

**Встановлення:**
1. Завантажте файл `…-ios.ipa` з
   [найновішого релізу](https://github.com/dariakyselytsia/cities/releases).
2. Під'єднайте iPhone кабелем і на телефоні натисніть **Довіряти цьому
   комп'ютеру**.
3. Відкрийте Sideloadly, перетягніть у нього файл `.ipa`, введіть свій
   Apple ID і натисніть **Start**. Якщо Apple надішле код підтвердження,
   введіть його.
4. На iPhone: **Параметри → Загальні → VPN і керування пристроєм** →
   ваш Apple ID → **Довіряти**.
5. На iOS 16 і новіших: **Параметри → Приватність і безпека → Режим
   розробника** → увімкнути, перезапустити телефон і підтвердити.

**Обмеження безкоштовного Apple ID:**
- Через **7 днів** гра перестане відкриватися. Знову встановіть той самий
  `.ipa` через Sideloadly: прогрес збережеться. Sideloadly може оновлювати
  підпис сам через Wi-Fi, поки комп'ютер увімкнений.
- Не більше 3 таких застосунків на одному iPhone.

Sideloadly — стороння програма. Ваш пароль вона передає тільки Apple, але
дехто для цього використовує окремий Apple ID.

## English

This is a test build for friends, until the game is in Google Play and the
App Store. The game works fully offline and collects no data
([privacy policy](https://dariakyselytsia.github.io/cities/privacy/)).

### Android

1. On the phone, open the [Releases page](https://github.com/dariakyselytsia/cities/releases)
   and download `…-android.apk` from the newest release.
2. Open the downloaded file. The phone asks to allow installs from this
   source ("Install unknown apps"): allow it once for your browser or
   Files app.
3. Tap **Install**. If Google Play Protect warns about an unknown
   developer, tap **More details → Install anyway**.

**Updates:** install a newer `.apk` over the old one. Your progress stays.

### iPhone

Apple doesn't allow installing apps outside the App Store without a paid
developer account. The free way: sign the game with **your own Apple ID**
using **Sideloadly** on a Windows PC or a Mac. You need a USB cable and
about 20 minutes the first time.

**Once, on the computer:**
1. On Windows, install **iTunes** and **iCloud** from Apple's website (not
   the Microsoft Store versions): without them Sideloadly can't see the
   iPhone.
2. Install [Sideloadly](https://sideloadly.io/).

**Installing:**
1. Download `…-ios.ipa` from the
   [newest release](https://github.com/dariakyselytsia/cities/releases).
2. Connect the iPhone with the cable and tap **Trust This Computer** on the
   phone.
3. Open Sideloadly, drag the `.ipa` into it, enter your Apple ID and click
   **Start**. If Apple sends a verification code, enter it.
4. On the iPhone: **Settings → General → VPN & Device Management** → your
   Apple ID → **Trust**.
5. On iOS 16 and later: **Settings → Privacy & Security → Developer Mode**
   → turn it on, restart the phone and confirm.

**Limits of a free Apple ID:**
- After **7 days** the game stops opening. Install the same `.ipa` again
  with Sideloadly: your progress stays. Sideloadly can refresh the
  signature by itself over Wi-Fi while the computer is on.
- At most 3 such apps per iPhone.

Sideloadly is a third-party tool. It sends your password only to Apple,
but some people use a separate Apple ID for it.
